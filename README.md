# 簡易ログ記録ツール

## 概要

本ソフトウェアは、ユーザーが入力した文字列を  
**現在時刻付きで標準出力およびログファイル（log.txt）に記録する**  
簡易ログ記録ツールである。

会話ログの保存、メモの記録、入力履歴の確認などを目的として使用できる。

---

## 使い方

プログラムを起動すると、以下の表示が行われ、入力待ち状態になる。

```text
ログ開始（終了するには exit ）
>

任意の文字列を入力すると、現在時刻が付与され、
標準出力に表示されると同時に log.txt に追記保存される。

[2025-12-10 10:00:00] hello

exit と入力すると、次のメッセージを表示してプログラムは終了する。

終了します。

保存されたログは、すべて log.txt に蓄積される。

動作環境

Python 3.6 以上

Windows / macOS / Linux

端末（PowerShell、bash 等）で実行可能

外部ライブラリ不要

※ 標準入力が対話的でない環境（CI 等）では、無限待ちを防ぐため即座に終了する。
