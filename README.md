このソフトは何をするためのものか

このソフトは、ユーザーが入力したメッセージを時刻付きでログファイル（log.txt）へ記録するための 簡易ログ記録ツール です。
会話履歴の記録、メモ取り、簡易チャットログなど、テキストベースで入力された内容を保存する用途で利用できます。

使い方

プログラムを起動すると、
ログ開始（終了するには exit ）
と表示され、入力待ちになります。

> の後に任意のメッセージを入力すると、

現在時刻を [YYYY-MM-DD HH:MM:SS] の形式で取得

log.txt に自動で追記保存される

画面には「✓ 保存しました」と表示される

ログを終了したいときは exit と入力
終了します。 と表示してプログラムが終了します。

保存されたログはすべて log.txt に蓄積されます。


このプログラムは Python 3 で書かれており、以下の環境で動作します。

Python 3.6 以上
（datetime モジュールと文字エンコーディング UTF-8 が利用可能な環境）

Windows / macOS / Linux 全てで動作

端末・コマンドライン（PowerShell、bash など）で実行可能

特別な外部ライブラリを使っていないため、ほとんどの Python 環境でそのまま動かせます。


プログラムの実行テストを行った結果は以下の通りです。

1. 通常入力テスト

入力：

hello


出力：

✓ 保存しました


log.txt の内容：

[2025-12-10 10:00:00] hello
